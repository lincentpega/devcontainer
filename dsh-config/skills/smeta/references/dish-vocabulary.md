# Receipt vocabulary (Uzbek / Central-Asian tea-house receipts)

Terms seen on such receipts and how to interpret them when mapping dishes to a
person's order.

## Osh (pilaf) dishes — the main course

| Receipt line | Meaning / hint | Typical unit price |
| --- | --- | --- |
| `Туй оши порция` | Full portion of tuй oshi | e.g. 50 000 |
| `Туй оши 0,7 порция` | Smaller/0.7 portion | e.g. 48 000 |
| `Чойхона ош порция` | "Teahouse" osh; person may write `чайхана` | e.g. 50 000 |
| `Зигир ош порция` | Zhigir osh | e.g. 52 000 |
| `Особый ош 0,7 порция` | "Special" osh; person may write `Махсус` | e.g. 48 000 |

## Add-ons / extras

| Receipt line | Meaning / hint | Typical unit price |
| --- | --- | --- |
| `доп.гушт` / `доп.гуш (...)` | Extra meat for the dish type it names | e.g. 30 000 |
| `двойное мясо` (person's wording) | = the `доп.гушт` for that person's osh type | — |

## Sides / salads / drinks

| Receipt line | Meaning / hint | Typical unit price |
| --- | --- | --- |
| `Бедана тухум` | Quail eggs | e.g. 2 000 each |
| `Катикли салат` | Katyk (yogurt) salad | e.g. 12 000 |
| `Ачичук` | Tomato–onion salad | e.g. 12 000 each |
| `Нон бутун` | Whole flatbread; person may write `хлеб` | e.g. 8 000 each |
| `Кук чой` | Green tea pot; person writes `чай` | e.g. 5 000 per pot |

## Mapping heuristics

- A person's `двойное мясо` always pairs with the osh type they ordered
  (`зигир двойное мясо` → `Зигир ош` + its `доп.гушт`).
- `туй ош` alone = `Туй оши порция`; `туй ош 0.7` = `Туй оши 0,7 порция`.
- Shared pots/portions (tea, bread, shareable salad) with multiple people but a
  single receipt line → split the line total evenly, round one person to make
  it exact.
- An explicit "остальное" person receives every line not claimed by the named
  diners.
